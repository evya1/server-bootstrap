# Distribution packages installed by server-bootstrap.
#
# One package per line. Blank lines, "#" comments, and trailing comments are
# ignored. Section headers select how failures are treated:
#
#   [required]  Installed as a single apt batch. If the batch fails, every
#               package is retried individually so one unavailable name cannot
#               block the rest. Only names that exist on every supported
#               Ubuntu/Debian release belong here.
#   [optional]  Best effort. Availability genuinely varies across releases
#               (universe-only, renamed, or backported), so a package that
#               cannot be installed logs a warning and never fails the run.
#
# Override without editing this file:
#   PACKAGES_FILE=/path/to/manifest.txt   read a different manifest
#   EXTRA_PACKAGES="pkg-a pkg-b"          append to [required]
#   SKIP_PACKAGES="pkg-a pkg-b"           drop from both sections
#
# Tools that are pinned to a checksummed upstream release rather than apt are
# installed elsewhere and are deliberately absent here: Node.js, uv, the GitHub
# CLI (gh), and the AI CLIs. See docs/CONFIGURATION.md.
